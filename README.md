# 🎭 Cloak of Moves - 双人联机卡牌对抗游戏

> **🎮 在线体验地址：[https://cloak-of-moves.pages.dev/](https://cloak-of-moves.pages.dev/)**

## 📖 游戏简介

**Cloak of Moves（迷雾行动）** 是一款全程使用国产AI大模型制作（零手工修改代码）的双人实时联机的策略卡牌对抗游戏。在迷雾笼罩的战场上，选择你的角色，运用独特的技能和卡牌组合，击败对手！

## ✨ 游戏特色

- **🌐 实时联机对战** - 支持房间号匹配和ID邀请两种模式，与好友即时对战
- **👤 10个可选角色** - 5种职业×2种性别，每个角色拥有独特的主动/被动技能
- **🗺️ 5种地图主题** - 森林、沙漠、冰原、火山、古城，每种主题可选特色地形
- **🌫️ 迷雾视野机制** - 限制视野范围，增加策略深度
- **🃏 策略性卡牌对抗** - 4种卡牌类型，信息博弈与战术选择并存

## 🎮 游戏规则

### 🎯 游戏目标

击败对方玩家，使其血量降为0。

### 🃏 卡牌类型

| 卡牌类型 | 图标 | 说明 |
|---------|------|------|
| **移动牌** | ↑→↓← | 控制角色向指定方向移动一格 |
| **攻击牌** | ⚔ | 对指定方向造成伤害（可选1格或2格距离） |
| **防御牌** | 🛡 | 抵消下一次受到的攻击（防御成功后失效） |
| **探查牌** | 👁 | 照亮视野，分为三种类型 |

**探查牌详细说明：**
- **行探查 👁↔**：照亮你所在行的所有格子
- **列探查 👁↕**：照亮你所在列的所有格子
- **环绕探查 👁**：扩大你的视野范围至1.5格

### 🗺️ 地图元素

| 元素 | 说明 |
|------|------|
| **障碍物** | 无法通过的格子，移动和攻击都会被阻挡 |
| **传送门 🔴🟡🔵** | 成对出现，踏入入口会传送至对应出口 |
| **迷雾** | 视野限制，只能看到周围一定范围内的区域 |

### 🌍 地图主题与特色地形

游戏提供5种地图主题，每种主题可选特色地形带来不同的战术体验：

| 主题 | 特色地形 | 描述 |
|------|---------|------|
| 🌲 森林 | 树木形 | 森林中的树木形成天然屏障 |
| 🏜️ 沙漠 | 沙丘形 | 沙漠起伏的沙丘地形 |
| ❄️ 冰原 | 菱形 | 冰原的菱形晶体结构 |
| 🌋 火山 | 火山形 | 岩浆河流造就不规则障碍 |
| 🏛️ 古城 | 废墟形 | 古城遗迹的断壁残垣 |

### ⚔️ 角色技能

每个角色拥有独特的技能，男性角色为**主动技能**（需手动触发），女性角色为**被动技能**（自动生效）：

| 职业 | 男性角色（主动技能） | 女性角色（被动技能） |
|------|---------------------|---------------------|
| 🧙 **法师** | ☄️ 天降陨石<br>随机在多个格子落下陨石造成伤害 | 💥 爆裂攻击<br>攻击可摧毁障碍物和传送门 |
| ⚔️ **骑士** | 🌀 旋风斩<br>对周围一圈造成范围伤害 | 🗡️ 坚韧突刺<br>攻击范围+1，初始血量+1 |
| 📖 **阅读者** | 📖 回忆过去<br>重新获得之前的探查视野 | 🔍 深度求索<br>环绕探查的范围额外+1 |
| 🗡️ **盗贼** | 🃏 盗为己用<br>复制对手第一张手牌加入自己手牌 | 👁️ 隔墙有眼<br>每隔几回合可偷看对手手牌 |
| 🏹 **弓箭手** | 🏹 百步穿杨<br>向四个方向发射穿透箭矢 | 🎯 天降箭雨<br>每回合开始随机落下箭雨攻击 |

### 📋 游戏流程

1. **选择角色** - 选择你喜欢的角色形象
2. **选择手牌** - 从发牌中选择3张卡牌作为手牌
3. **先手调整** - 先手玩家调整出牌顺序
4. **后手窥探** - 后手玩家可选择查看先手的第一张或最后一张手牌
5. **后手调整** - 后手玩家调整出牌顺序
6. **交替出牌** - 双方交替出牌，先手玩家先出
7. **回合结束** - 3张牌打完后进入下一回合

### 🔍 信息可见规则

- 后手玩家可选择查看先手玩家的**第一张**或**最后一张**手牌
- 先手玩家会得知后手玩家选择查看了哪张牌
- 双方都只能看到对方的一张手牌

## 🚀 快速开始

### 在线游玩

直接访问 **[https://cloak-of-moves.pages.dev/](https://cloak-of-moves.pages.dev/)** 即可开始游戏！

### 本地部署

#### 1. 克隆项目

```bash
git clone https://github.com/linyrlyrical/cloak-of-moves.git
cd cloak-of-moves
```

#### 2. 安装依赖

```bash
# 安装服务器依赖
cd server
npm install

# 安装客户端依赖
cd ../client
npm install
```

#### 3. 启动服务器

在 `server` 目录下执行：

```bash
npm start
```

服务器将在 `http://localhost:3000` 启动

#### 4. 启动客户端

在 `client` 目录下执行：

```bash
npm run dev
```

客户端将在 `http://localhost:5173` 启动

#### 5. 测试游戏

1. 打开两个浏览器窗口，访问 `http://localhost:5173`
2. 在第一个窗口点击"创建新房间"，会显示房间号
3. 在第二个窗口输入房间号，点击"加入房间"
4. 游戏开始！

## 🌐 部署说明

### 后端部署 (Render)

1. 在 [Render](https://render.com/) 创建新的Web Service
2. 连接GitHub仓库
3. 配置如下：
   - **Build Command**: `cd server && npm install`
   - **Start Command**: `cd server && node index.js`
4. 添加环境变量（如需要）

或直接使用项目中的 `render.yaml` 配置文件。

### 前端部署 (Cloudflare Pages)

1. 在 Cloudflare Pages 创建新项目
2. 连接GitHub仓库
3. 配置如下：
   - **构建命令**: `cd client && npm install && npm run build`
   - **输出目录**: `client/dist`
4. 设置环境变量 `VITE_SERVER_URL` 为后端服务器地址

## 🔧 开发指南

### 本地调试

服务器和客户端都有详细的日志输出：

**服务器端日志：**
- `[连接]` - 连接相关日志
- `[事件]` - 事件处理日志
- `[错误]` - 错误日志

**客户端日志：**
- 打开浏览器控制台 (F12)
- 查看 `[客户端]` 开头的日志

### 常见问题

#### 端口被占用

```bash
# 查找占用端口的进程
netstat -ano | findstr :3000    # 查找3000端口
netstat -ano | findstr :5173    # 查找5173端口

# 终止进程（将 PID 替换为实际进程ID）
taskkill /F /PID <进程ID>
```

#### 无法连接服务器

1. 确保先启动服务器，再启动客户端
2. 检查 `client/.env.development` 中的 `VITE_SERVER_URL` 配置
3. 检查防火墙是否阻止了端口

#### 模块导入错误

确保根目录 `package.json` 包含 `"type": "module"`
